# Лабораторна робота №1: Основи роботи з JavaScript

**Тема:** Основи роботи з JavaScript  
**Мета:** Оволодіти практичними навичками по впровадженню об'єктів JavaScript в HTML-документ та використанням базових конструкцій мови сценаріїв JavaScript.  
**Студент:** Бігун Денис  
**Варіант:** 3 (номер у журналі: 3)  

---

## Структура проекту

- `index.html` — основна сторінка з розміткою для всіх рівнів завдань.
- `style.css` — стилізація інтерфейсу та динамічних елементів.
- `script.js` — реалізація логіки завдань за стандартом ES6+ (`<script type="module">`).

---

## Опис виконаних завдань (Варіант 3)

### Рівень 4–6 балів:
1. **Завдання 1:** Виведення діалогового вікна `alert`, після натиснення "ОК" — відображення у вікні браузера фрази `"Hello, Бігун Денис!"`.
2. **Завдання 2:** Відображення діалогового вікна `confirm` з кнопками "Ок" і "Відміна" та виведення повідомлення про те, яку з кнопок було натиснуто.
3. **Завдання 3:** Скрипт виводить таблицю множення для числа 3 (остання цифра номера у журналі).

### Рівень 7–9 балів:
1. **Завдання 1:** Функція перевіряє парність числа 3 і виводить результат у кольоровому абзаці (червоний колір, оскільки число 3 — непарне).
2. **Завдання 2:** Функція створення пароля на основі імені («Денис») та номера у журналі (3) за формулою: `перші 3 літери імені + номер * 2` -> `"Ден6"`. Результат виводиться у блоці `<div>`.
3. **Завдання 3:** Функція приймає три оцінки через `prompt`, розраховує середній бал і виводить його в динамічно створений блок з `id="3"`.
4. **Завдання 4:** Скрипт запитує кількість студентів та їхні прізвища й імена, відображаючи кожного студента у вікні браузера одразу після введення.

### Рівень 10–12 балів:
1. **Завдання 1:** Список `<ul>` з літерами імені («Денис»). При наведенні миші (`mouseover`) на кожну літеру спрацьовує `alert` із цією літерою.
2. **Завдання 2:** Скрипт у циклі запитує прізвища та імена студентів, доки користувач не натисне кнопку "Відміна" у вікні `prompt`. Студенти додаються на сторінку після кожного введення.
3. **Завдання 3:** Кнопка «Показати блоки» та контейнер `id="letters"`. При натисканні для кожної літери прізвища («Бігун») створюється блок `<div>`. При наведенні курсору показується повідомлення `«Це літера [ ]»`. При повторному натисканні контейнер очищається.
