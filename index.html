Рівень 4–6 балів

Базовий рівень

Завдання 1. Діалогове вікно alert та привітання

Скрипт, який спочатку виводить діалогове вікно, а після натиснення «ОК» виводить у вікно браузера: "Hello, [Ваше прізвище та ім'я]!"

Завдання 2. Діалогове вікно confirm ("ОК" / "Відміна")

Відображає вікно з кнопками «Ок» і «Відміна» та повідомляє у вікні браузера, яка саме кнопка була натиснута.

Завдання 3. Таблиця множення для числа 3

Виводить таблицю множення для числа, що дорівнює останній цифрі номера у журналі (для варіанта 3 — число 3).

Рівень 7–9 балів

Середній рівень

Завдання 1. Перевірка на парність/непарність

Функція перевіряє номер у журналі (3) і виводить результат у кольоровому абзаці (парне — зелений, непарне — червоний).

Завдання 2. Генерація пароля

Функція створює пароль на основі імені («Денис») та номера у журналі (3) за формулою: перші 3 літери імені + номер * 2. Виводить у блоці <div>.

Завдання 3. Середнє арифметичне 3 оцінок у динамічному div

Запитує три оцінки через prompt, обчислює середнє значення та виводить у динамічно створений блок з id="3".

Завдання 4. Введення списку студентів за кількістю

Запитує кількість студентів і потім послідовно їхні прізвища та імена, відображаючи кожного студента на сторінці одразу після введення.

Рівень 10–12 балів

Високий рівень

Завдання 1. Список літер імені з alert при наведенні

Список <ul> з літерами імені («Денис»). При наведенні курсору миші на кожну літеру показується alert із цією літерою.

Завдання 2. Введення студентів до натискання «Відміна»

Запитує прізвища та імена у циклі доти, доки користувач не натисне кнопку «Відміна» у діалоговому вікні prompt. Результати виводяться після кожного введення.

Завдання 3. Динамічні блоки літер прізвища

Кнопка «Показати блоки» створює для кожної літери прізвища («Бігун») блок <div> у контейнері id="letters". При наведенні виводиться alert «Це літера [ ]». При повторному кліку контейнер очищається.
